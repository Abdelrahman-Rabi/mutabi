# Reviewer source readiness — 10 October 2026

The reviewed source is prepared for the public [Mutabi repository](https://github.com/Abdelrahman-Rabi/mutabi). The downloadable source package can also be generated locally with `scripts/package_submission.py`.

The README's default path is `python run_demo.py` (Windows launcher: `py -3`; macOS/Linux: `python3`). Python 3.10+ must already be installed. No package installation, API credentials, Node.js or build step is required for the default UI and curated workflow demonstration.

`python run_demo.py --check` executes seven end-to-end checks in temporary state under `runtime/`. It exercises the actual workflow and business tools, uses no live model and leaves existing browser workspaces unchanged. `--json` returns evidence suitable for automated review. These checks establish tested synthetic behavior, not real-world impact or general language-model accuracy.

The source ZIP is generated by `scripts/package_submission.py`. It contains source, static UI assets, synthetic input fixtures, tests, documentation and launchers. The allowlist excludes `.env`, credentials, `.venv`, generated databases, browser sessions, recordings, video exports and `.git`. `deliverables/mutabi-source-manifest.json` lists included files and SHA-256 checksums.
